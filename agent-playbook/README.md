# 工程协作技能输出

本目录存放从 AI 会话中提炼的通用约束与可复用工作流程。它是输出目录，不会自动安装技能或覆盖其他项目规则。

- [AGENTS.md](AGENTS.md)：可供目标项目合并的共用约束；项目差异应显式说明，当前用户指令优先。
- [测试验收](skills/acceptance-qa/SKILL.md)：测试矩阵、分层验证与验收交接。
- [缺陷记录](skills/bug-record/SKILL.md)：形成可复现、可分派、可验收的缺陷记录。
- [根因排查](skills/root-cause-investigation/SKILL.md)：以证据解释原因、历史正常条件和失败触发变化。
- [发布交付](skills/release-delivery/SKILL.md)：基线、范围、制品、迁移、验收和回退。

## 使用与维护

按目标工具的技能目录约定，复制需要的完整 skill 文件夹；AGENTS.md 单独评审合并到目标项目。每个 skill 可独立使用，不依赖其他技能已经安装。目标项目的命令、环境、凭据和文档格式必须现场读取，不从历史记录直接照搬。

首版来源于 2,750 份归档文件的关键词筛选及抽样阅读，未声称逐篇审计或完成真实任务行为验证。归档条数不等于独立会话数。用户当轮提供的数据库、时区和测试规则作为当前明确要求；历史个案仅提炼流程，不赋予生产操作、外部消息或提交权限。

后续按真实使用反馈迭代。候选扩展包括限定范围 Git 交付、设计评审、数据库迁移对账、文档一致性；当前不建立空目录。不要复制会话中的密码、Cookie、Token、真实客户数据到技能中。
